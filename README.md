# متجر إلكتروني — واير فريم هاي فيديليتي

High-fidelity **e-commerce wireframe** with Saudi Arabic content. No brand, no logo (temporary red dot), no images (grayscale placeholders), no hyperlinks — pure structure for handoff.

- RTL single page: utility bar, search header, category nav, hero + promos, category tiles, flash deals + countdown, best sellers, promo banners, new arrivals, trust strip, newsletter, footer.
- Interactive: cart drawer (localStorage), mobile menu, bottom tab bar, add-to-cart, countdown.
- Grayscale placeholders, IBM Plex Sans Arabic. Vanilla HTML/CSS/JS.

## تشغيل
```bash
node serve.js   # http://localhost:4774
```
