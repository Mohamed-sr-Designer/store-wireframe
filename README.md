# متجر لحوم وذبائح — واير فريم هاي فيديليتي

High-fidelity **meat & livestock store wireframe** (structure modeled on kabshnajd.com) with Saudi Arabic content. Grayscale placeholders + **red brand accent** — no real brand, no images, no navigation links.

- RTL single page: utility bar, search header, category chips, hero «عرض الأسبوع» + countdown, جميع الأقسام, product tabs (الأكثر مبيعاً/تخفيضاً/العروض), promo banner, بلدي ومرابي shelf, نعيمي كشميري shelf, stats band, banners, المطبخ (ولائم/إيدامات/سلطات/حلا), «آخر عملية شراء» live ticker, trust strip, app/newsletter, footer.
- Saudi meat catalog (بوكسات نعيمي/حري/سواكني/رفيدي، مفروم، حاشي، عجل، ولائم) with ر.س pricing.
- Interactive: cart drawer (localStorage), mobile menu, bottom tab bar, product tabs, countdown, live ticker.
- Grayscale wireframe + red accent (`--brand:#c1121f`); red-dot logo. Vanilla HTML/CSS/JS.

## تشغيل
```bash
node serve.js   # http://localhost:4774
```
